# 《猫忍不住》关卡布局实体版 v2

本版把第一章/第二章/第三章白盒布局进一步实体化。

## 已落实

- L01–L12：确定性的内部墙体与空间分隔。
- 墙体实际使用 `StaticBody2D + RectangleShape2D`，猫可被地图结构挡住。
- Ninja 固定路线作为最高优先级：路线附近自动开出 34px 级走廊，避免白盒墙误切 Ninja 主路线。
- 水面 / 断桥 / 猫隧道 / 快捷空间都有独立的视觉层。
- 起点 / 终点保留淡色锚点，方便关卡调试。
- 不使用随机地图生成；随机装饰仍由旧版确定性装饰逻辑负责。

## 当前限制

- 当前环境没有 Godot 4 Runtime，因此没有做引擎级启动、碰撞和移动实机验证。
- JumpPoint 仍是白盒空间标记；现有 CatController 尚未实现独立的跳跃传送逻辑，因此本版没有伪造“按 Space 一定会跳”的功能。
