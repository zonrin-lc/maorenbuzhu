# 《猫忍不住》v1.5.4 音效层级与动作同步

本版只复用工程内现有音频：成功、失败、读图、卖萌、狗叫。没有新增外部音频。

## 触发链

- 猫开始咬/推/互动：`SFX_INTERACT`，动作开始即触发。
- 猫叼取：`SFX_PICKUP`，拾取成功后触发。
- 放置/桥/水沟/毒雾/炸药/蒺藜处理：`SFX_PLACE`，事件成功时触发。
- 猫洞/跳点：`SFX_SHORTCUT`，位移完成后触发。
- 忍者掉心：`SFX_DAMAGE`，damage signal 到达即触发。
- 路线切换 / 双线程切换：`SFX_ROUTE_CHANGE`。
- Boss Phase 变化：`SFX_BOSS_PHASE`。
- Boss 击败：`SFX_VICTORY`。
- F 喵叫：继续保留素材缺口状态，不把错误音效冒充猫叫。

## 防噪

同类音效使用 80–450ms 冷却；四路 SFX 同时繁忙时不强抢占，避免连续事件造成爆音。
