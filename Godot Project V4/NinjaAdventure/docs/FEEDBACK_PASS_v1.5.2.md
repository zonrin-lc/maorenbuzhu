# 《猫忍不住》v1.5.2 反馈品质 Pass

## 目标
不新增玩法规则，只提升玩家对“我刚刚做了什么 / 忍者发生了什么 / 路线为什么改变”的即时可读性。

## 已接入
- 事件成功：顶部结果横幅 + 世界反馈闪光 + 左下事件徽记。
- 事件失败：危险横幅 + 红色闪光 + 失败原因。
- 忍者掉心：红色屏幕脉冲 + 剩余心数。
- 怀疑值跨过 25/50/80：眼睛提示徽记。
- 猫动作：叼取/喂狗/派狗/喵叫/卖萌等即时动作徽记。
- 捷径成功：独立的捷径横幅。
- 路线切换：L07/L10 显式提示“忍者改线”。
- Boss Phase：阶段切换横幅和轻度屏闪。
- 结算卡片：淡入+上移，猫爪缩放揭示。

## 音频原则
复用现有 `success / fail / emote / dog / read_map`，不新增外部音频素材；玩法规则和数据判定不因反馈层改变。

## 验收
本版本只做源码/资源静态检查。当前环境没有 Godot 4 Runtime，因此不把静态通过等同于实际运行通过。
