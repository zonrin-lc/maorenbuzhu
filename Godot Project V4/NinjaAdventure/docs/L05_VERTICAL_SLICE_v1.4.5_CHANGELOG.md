# 《猫忍不住》L05「月夜码头」垂直切片 v1.4.5

本轮依据 GDD v1.3 的第 2 关设计，补齐 6 事件主线：

1. 守卫 A：喵叫引开
2. 恶狗：Q 叼鱼肉，E 投喂
3. 断桥：E 推桥
4. 毒雾 / 流沙：Q 叼解毒药，E 放置
5. 守卫 B：守卫 A 离岗 8 秒后换岗到路线
6. 铁蒺藜：最后的高压清路点

额外实现：
- Q 叼取节点（鱼肉 / 解毒药）
- Guard B staging → timed route activation
- Poison failed state：每 5 秒对忍者扣 1 心
- L05 EventLog 记录 Guard B 换岗与毒素 tick
- L05 HUD 显示换岗倒计时
- 码头局部碰撞白盒分区

静态验证：资源路径、事件数量、脚本引用均需由 Godot 4 编辑器进一步实机验证。


## v1.4.5.1 修正

- 修复 L05 事件失败后因后续成功 Flag 未写入而产生的软锁。现在按事件 `resolved_state` 推进，失败仍会消耗容错但不会卡住后续关卡。
- 守卫 A 成功或失败离岗都会启动守卫 B 的 8 秒换岗计时。
- 鱼肉与解毒药现在都有随身携带视觉反馈。
