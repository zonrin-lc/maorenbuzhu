# L12 Boss Vertical Slice v1.4.12

## 目标
把守门武士的三个机关变成真正的分阶段 Boss 闭环，并修正“一个机关就可提前结束”的逻辑。

## 本轮改动

- L12 E01 完成后才开放战前准备机关。
- 吊车 / 酒葫芦只在 Boss 启动前可处理；Boss 启动后自动失效。
- 吊车预备伤害 40%，酒葫芦预备伤害 30%。
- Phase 2 才开放战中蒺藜，成功造成 30% 伤害。
- 三机关全部成功：Boss HP 归零，正常击败。
- 仅 1–2 个机制：Phase 3 撤退并让 Ninja 最终承受 2 心损失。
- 0 个机制：Phase 3 开启应急门；未及时救援则任务失败。
- L12 Boss 不再允许只靠一个机制就无条件结束战斗。
- Boss 场景位置校正到设计中的战斗区域。
- HUD 增加 Boss Phase / HP / 三机关状态 / 应急状态。

## 关键验证

A. 0 机关 → Phase 3 → 应急窗口 → 无救援 4 秒后失败。
B. 1 机关 → Phase 3 → Boss 撤退 → Ninja -2 心 → 正常结算。
C. 2 机关 → Phase 3 → Boss 撤退 → Ninja -2 心 → 正常结算。
D. 2 战前 + 蒺藜 → Boss HP 0 → Boss defeated → 正常结算。
E. Boss 启动后无法再次触发吊车/酒葫芦。
