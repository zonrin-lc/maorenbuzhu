# 《猫忍不住》v1.5.6 输入体验整合

## 本版定位
在 v1.5.5 UI/结算统一基础上，完成键鼠、手柄、触控输入统一，避免玩法代码感知具体设备。

## 输入设备
- KEYBOARD_MOUSE：默认桌面输入
- GAMEPAD：检测手柄按钮/摇杆输入
- TOUCH：检测屏幕触控；移动端自动保持触控层

## 默认手柄
A 互动 / X 叼取 / B 喵叫 / Y 卖萌 / LB 跳跃 / RB 疾跑 / START 暂停 / LS 重开。

## 触控布局
左下虚拟摇杆；右下 2×3 六键布局（互动、叼取、喵叫、卖萌、跳跃、疾跑）。控件尺寸按屏幕短边缩放。

## HUD
顶部显示当前设备；底部操作提示根据最近输入设备更新。触控模式隐藏底部键位文字，避免与虚拟按钮重叠。

## 状态同步
CatController 使用 set_carry_item() 修改携带物，并通过 carry_changed 触发 UI 更新。
