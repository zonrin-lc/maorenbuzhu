# 历史文档归档

本目录保存**历史版本**的设计与审查文档。根目录只保留当前生效文档（见下），避免「哪个才是当前真相」的歧义。

## 当前生效文档（位于仓库根目录）

- `《猫忍不住》_GDD_整合版_v1.7.0.md` —— 当前设计合同（GDD 顶部标题 = v1.7.0）
- `《猫忍不住》_v1.7.0_发布阻塞修复记录.md` —— 当前发布收口记录
- `《猫忍不住》_GDD_整合版_v1.7.0.md` 交叉引用的历史审查件，均已移入本目录

版本序列约定：**v1.0 ~ v1.6.x 为内部迭代/审查序列，v1.7.0 为首个对外发布版本**。

- `《猫忍不住》_GDD_v1.3_审查报告.md` —— 对 GDD v1.3 的一次审查（其审查对象为当时的 v1.3，故保留 v1.3 标签，不并入当前版本）

### 各轮实现审查 / 收口记录
- `《猫忍不住》_v1.6.0_实现审查记录.md` —— 设计合同 vs 实现（第一轮）
- `《猫忍不住》_v1.6.1_ReleaseHardening_收口记录.md` —— Release Hardening 收口
- `《猫忍不住》_v1.6.2_审查与修复记录.md` —— 第三轮审查修复

### 历史版本标记
- `VERSION_v1.5.6.txt` / `VERSION_v1.5.7.txt` / `VERSION_v1.6.0.txt` —— 早期版本说明（带日期的变更描述）

> 当前版本标记：`Godot Project V4/NinjaAdventure/VERSION_v1.7.0.txt`

## 保留原则

归档文件**一律不改名、不改写**，以保留其「审查对象 / 记录版本」的准确性（例如一份 v1.3 的审查报告不应被改名为 v1.7.0）。当前 GDD 中对这些文件的引用已补上 `docs/archive/` 路径以便定位。
