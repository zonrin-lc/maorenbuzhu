# 《猫忍不住》v1.2.23
## 12关 Playtest / Balance Matrix

> 目的：把 v1.2 的“难度曲线”从概念判断变成可测试参数。
> 本文中的数值分为两类：
> - **冻结基线**：来自前置 GDD / System Spec 的既定参数。
> - **测试目标**：v1.2.23 新增的量产测试基线，需通过实际试玩后再冻结。

---

# 1. 全局测试原则

1. 不用“感觉难/简单”作为结论，使用通关率、失败原因、完成时间、怀疑峰值、忍者剩余 HP、事件顺序正确率作为主要指标。
2. 玩家失败后必须能指出下一次会改变的具体行为；否则优先修可读性，不先降难度。
3. 所有关卡继续遵守：固定路线、脚本分支、事件驱动；不以随机 AI 作为难度来源。
4. 最高评价不能只奖励无风险路线；三猫爪继续采用表现条件集合。
5. 结算动画不能成为重复试玩的时间墙，重复挑战默认压缩到 8–12 秒。

# 3. 单关平衡卡

## L01 第一份差事

- 关键参数：Tripwire 0.8s；Guard 事件教学；Watergap 3s 犹豫。
- 目标：6/8 新玩家无需口头提示找到第一危险；5/8 会主动跑到忍者前方。
- 允许失败：首次可接受 1 次；第二次应能明确指出原因。
- 过难信号：超过 2 名新玩家完全等忍者走到危险点才开始行动。
- 过易信号：8/8 首通均无任何赶场压力体验。

## L02 他总是踩同一个坑

- 核心：连续事件之间制造最低 1 次真实赶场。
- 建议窗口：两个关键 EventPoint 间至少保留 0.8–1.5s 的“必须继续移动”压力。
- 目标：5/8 首通玩家会主动使用疾跑。
- 失败归因：FAIL_TOO_LATE 应占本关失败主因的主要部分，但不能高到让玩家只学会“无脑 Shift”。

## L03 谁在看猫

- 核心冻结：猫出现本身不增加怀疑；人类式动作被看见才累积；离开停止新增；卖萌清除已有怀疑。
- 阈值：25 Notice / 50 Alert / 80 High / 100 Broken Cover。
- 目标：5/8 能主动区分“被看见”和“做事被看见”；4/8 会主动尝试卖萌。
- 过难信号：玩家把普通露面理解成失败原因。
- 过易信号：玩家可以无视卖萌资源，怀疑系统几乎从不触发。

## L04 村口大事故

- 核心：第一次正式排序题。
- 目标：4/8 失败后会改变事件顺序；4/8 能解释一条因果关系。
- 两种主路线必须都可过关：稳健 / 快捷。
- 过难信号：玩家只能猜顺序，无法从地图信息预测后果。

## L05 月夜码头

- 核心：Q 叼取 / 放置。
- 冻结基础：CARRY_SPEED_MULT = 0.85；鱼吸引半径 200px；狗绑定约 20s。
- 目标：5/8 主动完成至少一次搬运；5/8 能在一次失败后改变搬运顺序。
- 关键 QA：叼道具期间被狗追，必须掉落道具并可恢复。

## L06 狗也能当队友

- 核心：Dog → Guard 联动。
- 标准解：鱼引狗。
- 高风险解：猫做诱饵。
- 目标：4/8 主动发现狗叫可以改变守卫状态。
- 过难信号：玩家以为 Dog 只是阻碍，不把它视为工具。

## L07 谁先走

- 核心：Guard A → Guard B 换岗链。
- 冻结基础：Guard 巡逻周期约 8s；引开后约 6s 回归。
- 目标：4/8 能在一次失败后解释“顺序导致路线变化”。
- 关键指标：玩家不是靠试错穷举，而是能看出预设换岗节奏。

## L08 最后一班船

- 核心：守卫线 + Dog 线 + 运输线。
- 目标：5/8 至少完成一次两事件以上连续联动；4/8 能讲出一条完整因果链。
- 过难信号：玩家开始随机四处跑，不再阅读路线。
- 过易信号：三条线程实际上彼此独立。

## L09 雷雨夜

- 核心：只提高环境压力，不增加新操作。
- 目标：玩家能在雷雨环境下保持基础路线阅读能力。
- 过难信号：视觉效果遮挡关键 EventPoint / Ninja Locator。
- QA：闪电不能造成关键时机的不可预测信息丢失。

## L10 炸药不能乱碰

- 核心：Dynamite 产生可预测的连锁事故。
- 冻结基础：爆炸半径 48px；猫被气浪掀飞但不扣血。
- 目标：4/8 能提前识别“炸药不是单点问题”。
- 过难信号：玩家只能记住“千万别碰”，却不理解爆炸会如何改变路线。

## L11 越靠近城门越忙

- 核心：Guard / Dog / Environment 三线程。
- 目标：5/8 在 Boss 前建立主动预处理意识；4/8 可连续管理两个以上事件。
- 失败主因不应全部集中于 TIMEOUT；应能观察到 ORDER / ROUTE / SUSPICION 三类失败。

## L12 守门武士

- Boss 三机关：Crane / Gourd / Caltrop。
- Crane：Boss 前准备；Gourd：Boss 前准备；Caltrop：Phase 2 战中处理。
- Emergency Rescue：仅保底，成功固定 1 猫爪，不提供正向资源奖励。
- 目标：5/8 在 Boss 已开始行动后仍继续移动；4/8 主动处理 Phase 2 Caltrop。
- 过难信号：玩家认为 Boss 战是观看动画；或者 4/8 以上测试者不知道第二阶段的主动任务是什么。
- 过易信号：玩家在 Boss 开始前完成全部有效动作，进入战斗后没有决策。

# 4. 三猫爪测试指标

## Paw 1

只验证：

```text
mission_complete = true
```

目标：正常的新玩家首通，不要求额外表现。

## Paw 2

继续采用：

```text
mission_complete
AND ninja_hp >= 2
AND max_suspicion < 80
```

## Paw 3

基础资格：

```text
mission_complete
AND ninja_hp >= 2
```

再按当前冻结规则，从 A–F（第三关 A–G）达到门槛。

测试时记录每位玩家属于哪一类满评价路径：

- SAFE：无伤 / 低怀疑 / 时间
- BALANCED：联动 / 捷径 / 时间
- RISKY：高风险救场 / 联动 / 快速完成

验收重点不是哪一种“最好”，而是三种路径都应当真实存在且可复现。

# 7. 调参优先级

当数据不达 Gate 时，不要先直接改所有参数。

### P0 可读性

路线看不懂、事件反馈不明、失败原因不清。

### P1 时间

再调整：

- Ninja speed
- Event window
- Sprint pressure
- Return timing

### P2 风险

再调整：

- Suspicion gain
- Dog duration
- Carry penalty
- Boss phase window

### P3 表现

最后才调整：

- 三爪阈值
- High-risk 权重
- Shortcut mastery

原则：

> **先解决“玩家不知道”，再解决“玩家来不及”。**
