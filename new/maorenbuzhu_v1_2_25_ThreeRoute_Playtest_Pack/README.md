# 《猫忍不住》v1.2.25 Three-Route Playtest Pack

本包用于 12 个主线关卡的首通体验、三路线和三猫爪测试。

核心文件：
- `docs/v1_2_25_ThreeRoute_Playtest_Spec.md`
- `data/maorenbuzhu_v1_2_25_ThreeRoute_TestCases.csv`

使用顺序：
1. 先按每关 SAFE 路线跑首通。
2. 第二次尝试观察玩家是否自然调整策略。
3. 再验证 BALANCED。
4. 熟练玩家再测试 RISKY。
5. 最后检查至少两种 3 Paw 路线是否成立。

本包的“成功信号 / 失败信号”是测试观察项，不代表已经有真实玩家数据。
