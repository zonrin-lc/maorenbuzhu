# 《猫忍不住》v1.2.7 — L01 完整教学关实施规格

## 目标

在 v1.2.6 最小切片基础上完成 L01 三事件教学闭环。设计基线来自 v1.1：第一关负责“提前赶场”，教学顺序是绊绳→守卫→小水沟；猫出现本身不产生怀疑，执行环境操作且被忍者看到才增加怀疑；卖萌用于清除累计怀疑。

## 玩家能力

| 能力 | 输入 | L01用途 |
|---|---|---|
| 移动 | WASD / 方向键 | 到事件点提前处理 |
| 疾跑 | Shift | 第一次赶场压力 |
| 互动 | E | 咬绳 / 推箱 |
| 喵叫 | F | 引开守卫 |
| 卖萌 | Ctrl | 清零怀疑，20s冷却 |
| 重开 | R | 失败/完成后重新加载场景 |

## L01 路线

```text
Start
  ↓
E01 绊绳
  ↓
E02 醉汉守卫
  ↓
E03 小水沟
  ↓
Goal
```

## 事件规格

### E01 绊绳
- Ninja 无犹豫，进入事件范围后开始计时。
- 猫在 48px 内按 E，交互 0.8s。
- 成功：`L01_TRIPWIRE_SAFE`。
- 失败：`FAIL_TOO_LATE`。

### E02 醉汉守卫
- Ninja 等待 3.2s。
- 玩家按 F 喵叫，守卫被吸引，事件立即解决。
- 喵叫本身不产生怀疑。
- 未处理：忍者受伤，L01失败。

### E03 小水沟
- Ninja 等待 3.2s。
- 猫在 48px 内按 E，推箱交互 1.2s。
- 成功：`L01_WATERGAP_SAFE`。
- 失败：`FAIL_TOO_LATE`。

## 怀疑规则

```text
猫被看见
→ 不涨

E互动动作帧 + Ninja视野内
→ +30

F喵叫
→ +0

Ctrl卖萌 + Ninja在150px内
→ 清零
```

当前垂直切片采用“近似前方视野”判定：Ninja 与猫距离≤120px 且 Ninja 朝向猫。后续生产版由 SuspicionSystem 独立成组件并替换为完整 90°视锥。

## 结算

- Mission Complete 触发 ScoreSystem。
- Ninja HP < 2 时最高只能 1 猫爪。
- 其余沿 v1.1 三猫爪规则。
- L01 当前白盒默认目标时间 60s。

## QA Smoke Test

1. 启动场景，Ninja 从 Start 沿固定路线行走。
2. 不处理 E01，约 2.2s 后失败。
3. 提前赶到 E01，E 按住/持续交互约0.8s，Ninja继续。
4. 在 E02 附近按 F，Guard 离开岗位，E02 完成。
5. 在 E03 附近按 E，推箱完成，Ninja到达Goal。
6. 在 Ninja 视线内执行 E，怀疑提升；按 Ctrl 且距Ninja≤150px，怀疑清零。
7. 失败或完成后按 R，应重载完整场景。
