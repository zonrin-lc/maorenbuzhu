## 1. 核心概念

**一句话：** 大名鼎鼎的忍者出任务，其实一路都是他的猫在暗中替他扫平一切——而他对此一无所知。

**玩家幻想：** 你不是英雄，你是英雄的猫。英雄在明处大摇大摆，你在暗处咬断陷阱绳、引开守卫、推箱子搭桥。结算时他在居酒屋吹"今天的任务顺利得出奇"，你在桌上舔爪子。

**类型：** 俯视角 · 潜行 × 解谜 × 反向护送（Reverse Escort）

**反转点（为什么好玩）：** "护送任务"是玩家最恨的任务类型——AI 蠢、走得慢、总往枪口上撞。本作把仇恨对象反转成爽点：那个蠢 AI 不再是你被迫保护的累赘，而是你的"作品"；你就是让一切顺利的幕后黑手。每一次他侥幸过关，都是你的杰作。

**三条设计戒律（所有取舍的仲裁标准）：**

1. **功劳永远归他，乐趣永远归你。** 任何让玩家"出风头"的机制都违背前提。
2. **蠢要可预测。** 玩家必须能读懂忍者的剧本，失误的挫败感应来自"我没算到"，而不是"他随机发病"。
3. **每个威胁都要有两副面孔：** 没处理时是危机，处理掉之后是笑话（他的得意反应本身就是奖励）。

## 2. 核心循环

```
读图观察（10 秒镜头巡游：忍者路线 + 沿途威胁依次高亮）
   ↓
忍者出发，沿固定路线行动（会犯蠢：踩陷阱/撞视野/悬崖边犹豫）
   ↓
你（猫）抢在他前面清扫障碍：咬绳 / 引怪 / 推物 / 投喂
   ↓
同时不能被他看见你干坏事——在他视野外行动，或卖萌蒙混
   ↓
他安全抵达终点 → 结算：居酒屋吹牛 + "顺利度"评价
```

**单局节奏（目标 3–6 分钟一关）：**

| 阶段 | 时长 | 体验 |
|---|---|---|
| 读图 | ~10 秒 | 紧张前的安静，玩家规划解法顺序 |
| 前段 | 1–2 分钟 | 单点威胁，建立信心与笑点 |
| 中段 | 1–2 分钟 | 威胁联动，排序解题，首次紧张峰值 |
| 尾段 | ~1 分钟 | 忍者"状态绝佳"走路加快，玩家疲于奔命（喜剧高潮） |
| 结算 | ~30 秒 | 吹牛 + 评分，情绪释放 |

**失败条件：**
- 忍者死亡（坠崖直接死；陷阱/守卫/中毒累计扣 3 颗心）→ 任务失败
- 怀疑值满 100 → 他吓得弃任务回家（"这猫不对劲！"）

**失败重试：** 立即回到读图阶段，事件点状态全部重置；死亡演出控制在 3 秒内，重试零加载。失败本身要带笑点（见 §6 各威胁的"失败演出"），降低挫败。

## 3. 玩家角色：猫

### 3.1 能力清单

| 能力 | 按键 | 说明 | 对应素材 |
|---|---|---|---|
| 移动 | WASD / 左摇杆 | 四方向移动 | `Actor/Animal/CatBlack/SpriteSheet.png` |
| 疾跑 | Shift | 短时间加速，消耗体力，有残影 | `FX/Particle` |
| 跳跃/攀爬 | Space | 跳上屋顶、树、箱子——立体机动是核心优势 | SpriteSheet 跳跃帧 |
| 互动（咬/推/拍） | E | 情境交互：咬断绳、推箱子/瓶子、拍飞小物件 | `Items/Action/Interact.png` |
| 叼取/放置 | Q | 叼起小道具（解毒药、鱼肉），放到指定位置 | 道具图标 |
| 喵叫 | F | 引开守卫/动物的注意力（对忍者无效——他只会说"哪来的猫"） | `Ui/Emote` 音符图标 |
| 卖萌 | Ctrl | 原地躺下翻肚皮：怀疑值清零，冷却 20 秒 | `Ui/Emote` 爱心图标 |

### 3.2 设计要点

- **猫不能战斗。** 不能杀守卫、不能拆陷阱外壳，只能"做手脚"。这保住了喜剧前提：忍者的功劳簿上不能有伤口。
- **体型优势：** 能钻桌底、篱笆缝、狗洞（忍者过不去的捷径），让你总能绕到他前面。
- **皮肤（5 种猫全用上）：** 黑猫（默认）、橘猫、白猫、灰猫、独眼猫（CatCyclop，三星全收集解锁）。纯外观，部分关卡触发隐藏对话彩蛋。

### 3.3 手感参数表（初值，原型阶段实测调整）

| 参数 | 数值 | 说明 |
|---|---|---|
| 行走速度 | 90 px/s | 约为忍者的 1.5 倍 |
| 疾跑速度 | 160 px/s | 体力 100，每秒耗 25，回复每秒 20 |
| 忍者行走速度 | 60 px/s | "得意忘形"状态下 66 px/s（+10%） |
| 忍者犹豫停顿 | 3–5 秒 | 事件点前的固定犹豫窗口，是玩家的黄金操作时间 |
| 互动耗时 | 咬绳 0.8s / 推箱持续 / 拍飞 0.3s | 咬绳有进度条，可被打断（他快看见时你得跑） |
| 喵叫半径 | 120 px | 声波可视化为扩散圈 |
| 卖萌冷却 | 20 秒 | 冷却期间图标置灰 |
| 叼取移动惩罚 | -15% 速度 | 叼着东西跑不快，增加"送货"紧张感 |

## 4. 隐蔽系统：不能被他发现

### 4.1 判定规则

- 忍者视野 = 前方 90° 视锥（半径 100 px）+ 周身 24 px 全向感知。
- 出现在视野里**本身不失败**——你是他的猫，在脚边打转很正常。他会冒一个爱心或音符气泡（小彩蛋）。
- **涨怀疑的是"通人性的行为"瞬间**：推箱、咬绳、叼着道具、拍飞物件的**动作帧**若落在他的视锥内，开始累积怀疑值。
- 怀疑值（0–100）：
  - 动作帧在视锥边缘：+30/次
  - 动作帧在视锥中心且持续 1 秒：+60
  - 达到 100：失败（他抱头："这猫绝对有问题！！"）
- 怀疑值**不随时间衰减**——它是全关累计压力，只能通过卖萌清零。这让卖萌成为稀缺资源管理。
- **卖萌（Ctrl）**：瞬间清零，冷却 20 秒。限制：必须在他视线内使用才有效（对着空气卖萌没用）；使用瞬间若正在叼着道具，道具掉落原地（喜剧细节：他看到的最后画面是猫从嘴里吐出一瓶药）。

### 4.2 其他目击者

- 守卫、村民对猫无反应。
- **狗会追猫**（天敌机制）：进入狗的 80 px 感知圈，狗直线扑来；猫被抓到不掉血，但会被叼着甩两下扔到远处（损失 2 秒 + 掉落口中道具）。狗叫（`Audio/Sounds/Creature/Dog.wav`）会吸引守卫——可被反向利用。

### 4.3 边界规则裁定（FAQ，程序实现的判定依据）

| 情况 | 裁定 |
|---|---|
| 猫挡在忍者行进路线上 | 他停下来："让让，小东西。"等 2 秒猫不走，他绕半步继续。不涨怀疑，但浪费他的犹豫窗口——软性惩罚 |
| 猫在忍者正脚下推箱子 | 涨怀疑（动作帧判定），箱子推不动（他踩着） |
| 卖萌冷却中被看见干坏事 | 怀疑照常累积，只能靠跑出视野等他自己"疑惑自我消解"（台词演出，怀疑值不变但暂停累积 3 秒——他忙着说服自己） |
| 忍者犹豫时猫在他眼前卖萌 | 他疑惑暂停延长 2 秒，爱心气泡："今天你也这么黏人。"——卖萌可当"拖时间"工具，一次事件点限一次 |
| 叼着道具被狗抓到 | 道具掉在原地，需回去捡 |
| 忍者死亡瞬间猫在视锥内 | 不追加怀疑（他已经死了），死亡演出照常 |

## 5. NPC 忍者设计（本作真正的"主角"）

### 5.1 行为模型

忍者不是随机蠢，而是**可预测的蠢**——玩家要读懂他的剧本才能提前布局。

```
出发 → 沿 waypoint 路线移动 → 进入【事件点】触发固定蠢反应（含 3–5 秒犹豫窗口）
     → 若威胁已被玩家处理：得意反应 + 记入事件日志
     → 若未处理：踩坑 → 扣血/死亡 → 惊吓/疼痛演出
     → 继续 → 抵达目标
```

### 5.2 情绪状态机（喜剧表现的发动机）

| 状态 | 表情素材（Ui/Emote） | 触发 | 行为效果 |
|---|---|---|---|
| 自信 | 得意脸 | 默认/通过威胁后 | 无 |
| 疑惑 | 问号 | 发现断绳/莫名的箱子/地上的药 | 停顿 2 秒，自我消解台词 |
| 惊吓 | 感叹号+汗 | 被玩家救下的惊险瞬间 | 冷汗粒子，后退半步 |
| 得意忘形 | 闪光 | 连续 3 个威胁顺利通过 | **移速 +10%，走路飘，下一事件点犹豫窗口 -1 秒**——顺风反而更危险，这是难度自平衡 |
| 怀疑 | 眼睛图标 | 看见猫干坏事 | 怀疑值累积中，视锥轻微摆动（他在找那只猫） |

### 5.3 台词池（每类随机抽取，避免重复笑点衰减）

**顺利通过（得意）：**
- "哼，这种程度也想拦我？"
- "感觉到了吗，这顺畅的查克拉流动。"
- "今天的我，无可挑剔。"

**疑惑自我消解（核心笑点，把一切归功自己）：**
- （看到断绳）"绳子自己断了……定是被我的杀气震断的。"
- （看到垫脚箱）"悬崖边恰好有箱子？呵，连老天都站在我这边。"
- （看到脚边的药）"哦？补给？看来村里人偷偷仰慕我。"
- （守卫莫名走开）"算他识相。"
- （喵叫引开守卫后）"方才那声猫叫……莫非是我的守护灵？"
- （看到掉进水里漂走的炸药桶）"炸药桶自己掉水里了？受潮的东西也配挡我。"
- （看到被拨到草丛里的铁蒺藜）"蒺藜都长歪了，这路修得不行。"

**惊吓（被救下的瞬间）：**
- "刚、刚才那阵风……是错觉吧。"
- "后背一凉……一定是昨夜没睡好。"

**得意忘形（连过 3 关后，走路变飘）：**
- "状态绝佳！！今夜没有人能拦我！"
- "要不要……干脆从正门进去？"（危险发言，下一事件点他不再犹豫）

**发现猫干坏事（怀疑累积）：**
- "嗯？？那猫刚才是不是推了个箱子？"
- "不可能……猫怎么会叼着药瓶……"
- "我一定是太累了。"（自我消解，怀疑值暂停累积 3 秒）

**死亡/失败：**
- （坠崖）"呜哇啊啊啊——任务、还没——"
- （怀疑值满）"那猫绝对有问题！！今天不宜出行！！"（抱头跑回起点）

**挡路：**
- "让让，小东西。"
- "别闹，办完正事给你带小鱼干。"

### 5.4 血量与容错

- 3 颗心。踩陷阱 -1，被守卫砍 -1，中毒每 5 秒 -1，坠崖直接死。
- 允许失误 2 次的容错服务于"差一点没救到"的紧张喜剧，而不是硬核折磨。
- 扣血演出要有喜剧性（被渔网吊起来晃、被守卫追砍绕树跑三圈后逃脱），让他"惨而不死"比直接死亡更好笑，也给玩家补救窗口。

## 6. 威胁设计卡（事件点规格库）

每个事件点是一个 Area2D，含：触发区、犹豫点（忍者停下的位置）、解法互动物、失败演出。**统一设计卡模板：触发 / 犹豫窗口 / 解法 / 失败演出 / 成功演出 / 参数 / 素材。** 所有素材均在素材包内。

### 6.1 绊绳陷阱 Tripwire

- **触发：** 忍者踩到绳 → 被渔网吊起，-1 心，吊 5 秒后挣脱
- **犹豫窗口：** 无（他直接踩）——玩家须在他到达前处理
- **解法：** 咬断绳子（E，0.8 秒进度条）
- **失败演出：** 吊在半空晃，挣扎，忍具掉一地："谁！谁干的！（心虚四顾）没人看见吧……"
- **成功演出：** 走过断绳时疑惑气泡 → 自我消解台词 → 得意
- **参数：** 咬绳耗时 0.8s；断绳后遗留绳头可被猫叼走藏进草丛（完美主义加分项，不强制）
- **素材：** 绳用 Line2D 程序化绘制（1–2 px 深色线）；网用 `Backgrounds/Vehicles/FishNet.png`；咬断瞬间 `FX/Slash/SpriteSheetSlash01.png`

### 6.2 巡逻守卫 Patrolling Guard

- **触发：** 忍者撞进守卫视锥 → 被追砍，绕树跑三圈后逃脱，-1 心
- **犹豫窗口：** 3 秒（他先观察守卫巡逻节奏，然后自信走进去——观察了个寂寞）
- **解法：** 喵叫把守卫引到路线外 / 拍飞陶罐在远处制造声响 / 用鱼肉引狗去吠守卫（高级连锁，狗叫 `Dog.wav` 吸仇恨）
- **失败演出：** 被追得绕树三圈，帽子被削掉，逃跑时顺手捡回帽子
- **成功演出：** 从守卫背后 2 米处大摇大摆走过，得意脸："他连我的影子都摸不到。"
- **参数：** 守卫巡逻周期 8 秒；声响吸引半径 150 px；守卫被引开后 6 秒回归岗位（回归时间点构成排序解题的压力）
- **素材：** `Actor/Character/SamuraiBlue/SamuraiRed`；声响 FX `FX/Smoke/SmokeCircular`（陶罐碎裂粒子 `FX/Particle/Vase.png`，Godot 工程已有 `content/destroyable/pot.tscn`）

### 6.3 悬崖/断桥 Cliff

- **触发：** 忍者到崖边犹豫 5 秒 → 硬跳 → 50% 概率摔死（读图时会标注，让玩家知道这是必解项）
- **犹豫窗口：** 5 秒（最长的操作窗口，通常安排给最复杂的解法）
- **解法：** 把 2 个木箱推下崖底垫脚（箱子在 30–60 px 外，需规划推箱路线避开他的视线）
- **失败演出：** 跳下，惨叫，屏幕下边缘伸出一只手扒住崖壁又滑下去
- **成功演出：** 踩着箱子轻盈跃过，疑惑："悬崖边恰好有箱子？"→ 自我消解
- **参数：** 箱子推速 40 px/s；猫站箱子上可跳更高（顺便当玩家自己的立体机动道具）
- **素材：** `Items/Object/CrateEmpty.png`（Godot 工程已有 `content/destroyable/crate.tscn`）；悬崖地形 `Backgrounds/Tilesets/TilesetRelief.png` / `TilesetHole.png`

### 6.4 毒雾/毒沼泽 Poison Mist

- **触发：** 忍者深吸一口气硬闯 → 中毒，每 5 秒 -1 心
- **犹豫窗口：** 4 秒
- **解法：** 把解毒药叼到他必经之路上显眼处（他会"哦？补给？"捡起来收好——注意他**不会主动吃**，需再拍一下药瓶滚到他脚边触发他弯腰捡）
- **失败演出：** 脸色发绿（调色 shader），边跑边呕（`FX/Particle/Leaf.png` 染绿），找到水缸狂灌水解毒
- **成功演出：** 路过毒雾全程屏息冲刺，出来后得意："闭气功夫，天下第一。"
- **参数：** 叼药移速 -15%；药瓶滚速 100 px/s
- **素材：** 毒雾 `FX/Environment/Fog.png` 染绿 / 流沙地表 `Backgrounds/Animated/QuickSand/QuickSand32x32.png` 染紫；药瓶 `Items/Potion/LifePot.png`（解毒）/ `MilkPot.png`

### 6.5 恶狗 Dog

- **触发：** 忍者怕狗！见到狗会绕远路——而绕远路必然撞进另一个威胁（组合拳设计）
- **犹豫窗口：** 3 秒（原地跺脚："可、可恶的畜生……"）
- **解法：** 用鱼肉把狗引到反方向（狗被鱼肉拴住 20 秒）/ 或干脆自己当诱饵引狗追你绕场一圈（高风险高笑点）
- **失败演出：** 绕远路，撞进隔壁铁蒺藜阵
- **成功演出：** 从狗旁边走过，狗睡得打呼，忍者踮脚走猫步（紧跟猫的实际动作，喜剧镜像）
- **参数：** 鱼肉吸引半径 200 px；拴住时长 20 秒
- **素材：** `Actor/Animal/Dog*` 6 种；鱼肉 `Items/Food/Fish.png`；狗叫 `Audio/Sounds/Creature/Dog.wav`

### 6.6 炸药桶 Dynamite Crate（替换原"蜂窝"——素材包无蜂窝/蜜蜂，炸药桶素材完整且更贴忍者主题）

- **触发：** 忍者路过时手贱上去敲一敲、拍一拍 → 引线被震开 → 爆炸，-1 心，炸成黑脸（调色），头发冒烟
- **犹豫窗口：** 无（手贱是即时的）——玩家须提前处理
- **解法：** 提前把炸药桶推进旁边的水里（受潮哑弹，漂走）/ 或咬断引线让它变成无害摆件
- **失败演出：** 轰！黑脸忍者从烟雾里走出来，抖了抖，继续走（假装无事发生）
- **成功演出：** 路过水边漂着的炸药桶，疑惑："受潮的东西也配挡我。"
- **参数：** 推桶速度同推箱 40 px/s；爆炸半径 48 px（猫在半径内会被气浪掀飞 1 秒，不扣血——喜剧风险）
- **素材：** `Items/Projectile/CrateDynamite.png`、`Dynamite.png`；爆炸 `FX/Elemental/Explosion`；引线 Line2D + `FX/Particle/Spark.png`；气浪 `FX/Smoke/SmokeCircular`

### 6.7 铁蒺藜阵 Caltrop（替换原"地刺阵"——`Caltrop.png` 是现成忍者主题素材）

- **触发：** 忍者自信走过散落一地的铁蒺藜 → 扎脚，-1 心，抱着脚单脚跳 10 秒
- **犹豫窗口：** 2 秒（他蹲下研究了一下，结论："摆错位置了，伤不到我。"）
- **解法：** 猫用爪子把蒺藜一颗颗拨/拍到路边草丛里（每颗 0.3 秒，共 4–6 颗，是"耗时型"解法，考验时间管理）/ 或推一块木板/空箱盖在上面当桥
- **失败演出：** 嗷的一声蹦起来，单脚跳，蒺藜挂在脚底，走两步抖一下
- **成功演出：** 走过干净的路面，得意："我说了吧，摆错位置了。"
- **参数：** 蒺藜 4–6 颗；拍飞单颗 0.3s；草丛藏身点用 `content/destroyable/grass.tscn`
- **素材：** `Items/Projectile/Caltrop.png`；拍飞 `FX/Attack/Claw`（猫爪特效，正好切题）

### 6.8 守门武士 Boss（第 3 关终点，组合机制，素材全部替换为包内资产）

猫无法伤害 Boss。设计 3 个可做的"手脚"：

1. **码头吊车货箱：** Boss 站在吊车（`Backgrounds/Vehicles/Crane.png`）吊着的货箱下方摆 pose。猫爬上吊车咬断吊绳（Line2D 绳 + 咬绳 0.8s 复用绊绳机制）→ 货箱砸下，Boss -40% 血。
2. **门口蒺藜：** 把 Boss 出场冲刺的必经之路上撒满铁蒺藜（猫叼着蒺藜袋一路撒，复用 §6.7 素材）→ 他冲锋时扎脚滑倒，-30% 血，喜剧性拉满。
3. **酒葫芦下药：** Boss 战前他会先喝一口放在石台上的酒葫芦（`Items/Object/Gourd.png`）壮胆。猫提前把"强力泻药"（`Items/Potion/LifePot.png` 染紫）拍进葫芦 → 开场他先跑茅房 10 秒，回来 -30% 血，还给了忍者摆 pose 的时间。

- 全做完：忍者一剑收掉残血 Boss，吹牛素材拉满。
- 只做 1–2 个：忍者苦战险胜（-2 心），吹牛台词变成"我让了他三招"。
- 一个没做：忍者被打出场地，任务失败。

## 7. 关卡设计

### 7.1 结构

每关 = A（出发点）到 B（任务目标）的一条路线，含 5–8 个事件点。开局 10 秒读图巡游，威胁依次高亮 + 一句提示字幕。

### 7.2 第 1 关《初出茅庐》逐节拍脚本（Beat Sheet）

> 场景：村庄（`map_village.tscn` 改造）。教学关，事件点 3 个，蠢得温和。

| # | 节拍 | 内容 | 教学目的 | 演出重点 |
|---|---|---|---|---|
| 0 | 开场 | 忍者在家门口接任务卷轴，抱猫举高："等我的好消息。"放下猫，出发 | 交代关系 | 猫被放下时翻个白眼（第一个笑点） |
| 1 | 读图 | 镜头巡游 10 秒：绊绳 → 醉汉守卫 → 小水沟，依次高亮 | 教会"先观察" | 字幕："他看不见的危险，都归你管。" |
| 2 | 事件点 1：绊绳 | 忍者匀速走来，无犹豫窗口。玩家须学会咬绳（E 进度条教学） | 基础互动 | 成功后他踩过断绳——疑惑——"被我的杀气震断的" |
| 3 | 事件点 2：醉汉守卫 | 守卫在路中间打晃。教学喵叫（F）引开 | 注意力机制 | 守卫循声走远，忍者得意通过 |
| 4 | 事件点 3：小水沟 | 忍者犹豫 3 秒要硬跳。教学推箱（E 持续推）垫脚 | 推箱 + 利用犹豫窗口 | 他踩箱跳过："连老天都站在我这边。" |
| 5 | 终点 | 忍者取得卷轴（`Items/Scroll/Scroll.png`），摆 pose | 闭环 | 猫跳上屋檐俯视他，夕阳 |
| 6 | 结算 | 居酒屋吹牛（本关实际事件生成台词）+ 猫爪评分 | 奖励与传播 | 镜头下移到桌下舔爪的猫 |

### 7.3 第 2 关《月夜码头》——组合关

- 场景：沼泽/码头（`environment/swamp` + `Backgrounds/Tilesets/TilesetWater.png` + 码头吊车/渔船 `Backgrounds/Vehicles`），夜晚
- 事件点 6 个：巡逻守卫 ×2、恶狗 ×1、断桥 ×1、毒雾/流沙 ×1、铁蒺藜 ×1
- **核心进阶：威胁联动。** 喵叫引开守卫 A，守卫 A 的巡逻空缺会让守卫 B 在 8 秒后换岗到路线上——解法有**顺序**，不是并行可解。读图阶段可看到巡逻节奏表。
- 新机制教学：叼取/放置（Q，解毒药与鱼肉）、狗追猫。
- 通关台词："码头的风都是为我让路的。"

### 7.4 第 3 关《天守阁》——Boss 关

- 场景：城堡外围 → 正门，夜晚，雷雨（`FX/Elemental/Thunder` 闪电 + 雨粒子 `FX/Particle/Rain.png`，Godot 工程天气系统现成）
- 事件点 8 个：守卫 ×2、炸药桶 ×2、铁蒺藜 ×1、悬崖 ×1、恶狗 ×1、毒雾 ×1
- **新压力：忍者全程得意忘形**（前两关的吹牛让他飘了），移速 +10%，犹豫窗口全部 -1 秒——玩家疲于奔命是刻意的喜剧设计。
- Boss 战见 §6.8。通关台词："那武士见我就跪了，大概是被我的气势震的。"

### 7.5 难度曲线与评分

- 第 1 关：单点威胁，时间宽裕
- 第 2 关：威胁联动，排序与路线规划
- 第 3 关：时间压力 + 多解 Boss

结算按"顺利度"给 1–3 个猫爪印：
- ★ 忍者满血过关
- ★ 怀疑值从未超过 50
- ★ 限定时间内过关

三星解锁独眼猫皮肤和"困难剧本"（忍者更蠢、走路更快、犹豫窗口更短）。

## 8. 结算：居酒屋吹牛（招牌画面）

每关结束进入居酒屋场景（`Backgrounds/Tilesets/Interior` 室内地块 + `Items/Food` 摆桌：寿司、烤串；酒葫芦 `Items/Object/Gourd.png`）：

1. **忍者拍桌吹牛**，台词由本关**事件日志动态生成**（模板拼接）：
   - 规则：每个被玩家暗中处理掉的威胁 → 一条吹牛句式。句式模板池 × 威胁类型 × 程度副词（由"惊险度"决定：玩家处理得越晚越惊险，他吹得越离谱）。
   - 例：`"那{数量}重{威胁名}阵？我{夸张动作}它就{荒谬结果}。"` → "那三重陷阱阵？我一个眼神它就自己散了。"
   - 老板娘（`Actor/Character/Woman` / `OldWoman`）固定捧场/拆台台词池："哎哟，大人好厉害～"（棒读）
2. **镜头缓缓下移**——你在桌下/柜台上舔爪子，头顶"……"气泡。
3. **评分弹出**（猫爪印 ×1–3）+ 固定吐槽字幕："他信了。他们又都信了。"
4. **回放小窗（预留）：** 右上角小窗静音循环播放本关玩家操作的 10 秒剪辑——他吹牛的每句话旁边对照你实际干的事。这是短视频传播的核心画面，预留 GIF 导出接口位置。

## 9. UI / HUD 与教学

### 9.1 HUD 布局

```
┌──────────────────────────────────┐
│ [忍者心情气泡]        [怀疑值·猫眼图标] │  ← 怀疑值用"半睁的猫眼"瞳孔开合度表现，不用数字条（保持喜剧调性）
│                                  │
│            （游戏画面）            │
│                                  │
│ [体力条]  [口中道具]   [喵叫][卖萌] │
└──────────────────────────────────┘
```

- **极简原则：** 怀疑值和体力是仅有的两个常驻仪表（体力条用 `Ui/Receptacle/LifeBarMini*.png`），其余全部情境化（交互提示 `Items/Action/Interact.png` 在可互动物上浮现；按键图标用 `Ui/Input/Keyboard` 现成套图）。
- **忍者的位置感知：** 屏幕边缘忍者方向指示箭头（`Ui/Arrow.png`），颜色随心情变化——玩家要随时知道"他走到哪了、心情如何"，这是决策依据。
- **猫眼怀疑值表盘：** 无现成素材，用 shader 程序化绘制（圆形瞳孔随怀疑值收缩/扩张），属于允许的程序化图形（同 Line2D 绳子）。

### 9.2 教学策略

- 无文字教程墙。第 1 关每个事件点首次出现时，屏幕下方一行字幕 + 按键图标（`Ui/Input/Tuto.png` 及 `Keyboard` 套图），演示一次后不再出现。
- 猫的所有能力在第 1 关教完（咬、叫、推），第 2 关教叼，第 3 关不教新东西，只加大压力。

## 11. Meta 与进度结构

- **章节结构：** 3 关为一个章节（村庄 → 码头 → 天守阁）。后续章节可换忍者（NinjaRed 更自负、NinjaGreen 更胆小——素材包 14 种忍者外观现成），同一套系统换不同"蠢法"。
- **存档：** 每关独立记录最佳评分、最快时间、已解锁皮肤。`user://save.cfg`。
- **收集品（可选）：** 每关藏 3 条**小鱼干**（`Items/Food/Fish.png`——替换原"铃铛"，素材包无铃铛且鱼干更贴猫的主题），藏在只有猫能钻的洞里——纯装饰性成就，不影响通关，服务探索型玩家。
- **彩蛋：** 用特定皮肤过关触发忍者的隐藏台词（如独眼猫："总觉得家里的猫眼神犀利了许多……错觉。"）。

## 13. 技术实现方案（Godot 4，基于现有 NinjaAdventure 工程）

现有工程已有：地图系统（`world.gd` + `Map` + 环境/天气）、敌人行为基座（`content/behavior`）、队伍/属性/武器系统、标题菜单、可破坏物（crate/pot/grass 可直接复用为互动物）。**大量复用，新增以下模块：**

### 13.1 新增场景与脚本

```
content/
├── cat/                    # 玩家猫控制器（新增）
│   ├── cat.tscn            # CharacterBody2D + 状态机
│   └── cat_controller.gd   # 移动/疾跑/跳/互动/叼取/喵叫/卖萌
├── npc_ninja/              # NPC 忍者（新增，本作核心）
│   ├── npc_ninja.tscn
│   ├── route.gd            # Waypoint 路线资源（每关一条）
│   ├── event_point.gd      # 事件点基类：进入触发蠢反应
│   ├── mood.gd             # 情绪状态机 + 气泡 + 台词池
│   └── suspicion.gd        # 怀疑值与视锥判定
├── hazard/                 # 威胁库（新增，每个对应 §6 一张设计卡）
│   ├── tripwire.gd / patrolling_guard.gd / cliff.gd
│   ├── poison_mist.gd / dog.gd / dynamite_crate.gd / caltrop.gd
├── interactable/           # 可互动物（咬/推/叼的统一接口 Interactable）
└── izakaya/                # 居酒屋结算场景（新增）
    └── boast_generator.gd  # 根据事件日志生成吹牛台词（模板拼接）
```

### 13.2 关键系统

- **事件日志（EventLog，本作数据中枢）：** 全程记录 `时间戳 / 威胁类型 / 玩家处理动作 / 处理时的惊险度 / 忍者反应`，供吹牛生成器、评分、回放剪辑三方消费。
- **事件点（EventPoint）：** Area2D + 类型枚举 + `disarmed` 状态。忍者进入触发 `ninja_react()`；未处理走失败演出分支，已处理走得意分支并写日志。
- **忍者视线检测：** 复用 `behavior_enemy` 的视锥思路，但检测对象反转为"猫的交互动作帧"。
- **读图预览：** 镜头巡游用现有 `CameraGrid` 扩展，威胁高亮用 shader 描边。
- **吹牛生成器：** 纯模板拼接（威胁句式池 × 程度副词池），不接 LLM——离线可控、笑点可调试。

| "看戏"比例过高 | 玩家清完障碍后只能干等忍者走完，无聊 | 犹豫窗口永远留一点"就差一点"的压迫；得意忘形加速机制让后半程永远紧张；关卡时长压死在 6 分钟内 |
| 笑点衰减 | 台词重复后喜剧失效 | 台词池每类 ≥5 条 + 按事件日志组合生成；通关后困难剧本换新台词池 |
| 解法唯一导致卡关 | 玩家找不到唯一解时挫败 | 每个威胁至少预留 2 种解法（标准解 + 高风险高笑点解，如肉身引狗） |
| 忍者 AI 不可控 | 复杂联动下出现意外行为破坏"可预测的蠢" | 事件点全部脚本化、离散状态机，**禁用连续物理决策**；蠢是演出，不是模拟 |
| 隐蔽判定太严/太松 | 怀疑值挫败或形同虚设 | M1 原型专门调参：视锥判定、累积速率、卖萌冷却，做成调试面板实时改 |
| 单手操作负担 | 叼取+移动+卖萌键位冲突 | 叼取/放置合并为 Q 单键；卖萌 Ctrl 可改键；手柄映射同逻辑 |
| 素材复用感过强 | 全部来自同一素材包，关卡间视觉雷同 | 环境调色（夜晚/雷雨/沼泽）、同一素材不同组合（吊车白天是码头布景、第 3 关变成 Boss 机关） |
